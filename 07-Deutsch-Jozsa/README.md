# 07 - Deutsch-Jozsa Algorithm

The Deutsch-Jozsa Algorithm is a quantum algorithm that determines whether a function is constant or balanced.

## Topics Covered

- Constant and balanced functions
- Quantum superposition
- Quantum oracle
- Hadamard gates
- Quantum interference
- Measurement
- Qiskit implementation
